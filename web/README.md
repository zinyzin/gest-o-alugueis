# Web App

Interface web responsiva (desktop, tablet, mobile no navegador).

**Stack:** React + Vite + TypeScript + TanStack Query + Socket.IO client.

## Setup (a implementar na Fase 1)

```bash
cd web
npm install
npm run dev
```

## Telas principais

- Login / gestão de usuários
- Cadastro do imóvel
- Inquilinos e contratos
- Lançamentos de receitas e despesas
- Dashboard (resumo, gráficos) e relatórios
